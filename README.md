# Ta-Te-Ti Accesible

Juego de Ta-Te-Ti (tres en línea) contra la máquina, accesible de principio a fin: se juega con teclado, lector de pantalla o pantalla táctil. Sin instalación y sin dependencias: HTML, CSS y JavaScript puro.

[Jugar ahora](https://martinbalda.github.io/ta-te-ti-accesible/)

## Características

- Tres niveles de dificultad: Fácil, Medio e Imposible.
- Torneos con cantidad fija de partidas o modo infinito.
- Marcador de victorias, derrotas y empates.
- Sonido opcional, con un tono distinto para ganar, perder o empatar.
- Modo claro y oscuro, con la preferencia guardada.
- Animaciones breves que respetan la preferencia de movimiento reducido.

## Accesibilidad

- Diseñado para cumplir WCAG 2.2 nivel AA.
- Se juega completo con lectores de pantalla: probado con VoiceOver (iOS), NVDA y JAWS (Windows) y TalkBack (Android).
- Navegación íntegra por teclado, con foco visible.
- El resultado de cada partida se anuncia en una región viva.
- Verificación automatizada con axe-core: cero violaciones.

## Cómo jugar

1. Elige un nivel de dificultad.
2. Define la cantidad de partidas del torneo (o marca "Infinitas").
3. Presiona "Iniciar torneo".
4. Coloca tu X en una celda vacía. Gana quien forme tres en línea; al completar el torneo se anuncia el resumen final.

## Controles

| Acción | Teclado | Táctil |
| --- | --- | --- |
| Entrar al tablero | Tab | — |
| Mover entre celdas | Flechas | — |
| Colocar ficha | Enter o Espacio | Tocar una celda vacía |
| Abrir ayuda | Tab hasta "Ayuda" y Enter | Tocar "Ayuda" |
| Cerrar ayuda | Esc | Tocar "Cerrar" |

## Ejecutar en local

Sin instalación ni servidor: descarga el proyecto y abre `index.html` en cualquier navegador moderno.
